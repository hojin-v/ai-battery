# AI Battery 0.1.24

`ai-battery setup`만으로 Claude와 Codex의 기본 사용량 표시를 설정할 수 있습니다. 0.1.23에서 Codex 자동 표시에 필요했던 추가 옵션은 더 이상 필요하지 않습니다.

## 변경 사항

- 기본 setup에서 Claude statusLine과 Codex 자동 표시를 함께 설정합니다. `setup codex`도 추가 옵션 없이 Codex 표시를 연결합니다.
- 원본 Codex 실행 파일, 기존 Codex 설정과 세션 기록은 유지합니다. 반복 setup 후에도 `reset settings`로 AI Battery의 변경을 복원할 수 있습니다.
- Codex 자체의 모델·디렉터리·브랜치 행을 변경하는 `--configure-codex-statusline`은 선택 사항입니다. AI Battery 사용량 표시에는 필요하지 않습니다.
- 자동 연동을 끄려면 `ai-battery setup codex --no-wrap-codex`를 사용합니다.
- POSIX 터미널의 종료 순서에 따라 Codex의 종료 코드가 0으로 바뀌던 문제를 수정했습니다. 사용량 조회가 실패해도 Codex는 계속 실행됩니다.

## 업데이트 후 사용

Windows와 WSL에 각각 설치했다면 각 환경에서 실행합니다.

```bash
npm install -g ai-battery@0.1.24
ai-battery setup
```

새 터미널을 열거나, setup이 안내하는 `source ...` 명령과 Bash의 `hash -r`을 실행하세요. zsh는 `rehash`를 사용합니다. Windows에서는 새 cmd/PowerShell을 엽니다. 이후에는 평소처럼 `claude`, `codex`를 실행하면 됩니다.

설정 복원과 npm 패키지 삭제는 계속 분리됩니다.

```bash
ai-battery reset settings && npm uninstall -g ai-battery
```
